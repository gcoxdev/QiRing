A guide to every QiRing page, control, and security setting.

Unlock & recovery

Unlock opens the encrypted vault with your master password. Recovery unlock uses the offline recovery key and immediately asks you to establish a new master password and recovery key.

QiRing cannot retrieve either secret. Store the recovery key somewhere separate from this computer, and use Lock whenever you leave the device.

Vault

The Ring on the left groups Qi by category. Search matches names, usernames, notes, and tags; the Tag selector applies an exact tag filter. The sort control cycles through A–Z, Z–A, and Custom ordering.

Select a Qi to edit its name, type, category, tags, website, credentials, icon, TOTP setup key, notes, security questions, and password history. Upload an icon or import the site favicon. Save before leaving; deleting a Qi requires confirmation and offers a temporary Undo action.

One-time codes: save a Base32 TOTP setup key with the Qi, then choose Show Current Code. Codes are derived locally from the saved key and device time.

Password profiles

Profiles define reusable password-generation rules. Choose the total length and the permitted minimum and maximum counts for uppercase letters, lowercase letters, numbers, and symbols.

Allowed Symbols restricts the symbol set. Avoid Ambiguous Characters removes easily confused characters. Test Profile previews a generated password without saving the profile. At least 1 profile must remain.

Vault health

Run Analysis checks credentials locally and reports weak, reused, and old passwords. Weak passwords are short or lack variety; reused passwords appear in more than 1 Qi; old passwords belong to Qi that have not been updated for 180 days.

Choose Open Qi beside an issue to review and update that entry. Passwords and password hashes are never sent to a network service for analysis.

Encrypted backups

Manual Export creates a portable encrypted backup protected by a separate passphrase. Keep that passphrase outside the backup file. Restore Preview authenticates a selected backup and shows what it contains before Restore is enabled.

Automatic Snapshots are local safety copies protected by vault encryption. Refresh reloads the available snapshot list; restoring a snapshot replaces the current vault and then locks QiRing.

Settings

Auto-lock minutes
Locks the vault after 1–1,440 minutes without qualifying activity.
Clipboard clear seconds
Attempts to clear a copied QiRing secret after 5–300 seconds, provided the clipboard still contains the same value.
Lock when minimized
Locks immediately whenever the QiRing window is minimized.
Lock when focus is lost
Locks when you switch to another window. Enable this for stronger shoulder-surfing protection.
Theme
System follows the operating-system appearance; Dark and Light keep a fixed QiRing theme.
Button display
Shows icon + label, icon only, or label only on supported controls. Navigation menu labels always remain visible; icon-only controls expose their names on hover.
Create snapshots after changes
Creates an encrypted automatic snapshot after supported vault changes.
Include settings in manual exports
Adds the encrypted application settings to newly created manual backup files.
Snapshots to retain
Keeps the newest 1–100 automatic snapshots and removes older copies beyond that limit.
Backup directory
Selects where automatic snapshots are stored. Choose a durable, user-owned location.
Rotate master password
Verifies the current password, re-encrypts the vault under the new password, and keeps the existing vault contents.
Replace recovery key
Verifies the master password, invalidates the old recovery key, and starts the save/verify ceremony for the replacement.

Settings are not persistent until you choose Save Settings. QiRing prompts you to save or discard pending changes before navigating or locking.

Navigation & shortcuts

Use the menu or Ctrl/⌘ 1–6 to open Vault, Password Profiles, Vault Health, Encrypted Backups, Settings, or Help. Ctrl/⌘ K focuses Ring search, Ctrl/⌘ S saves, Ctrl/⌘ N creates a new Qi or profile, and Ctrl/⌘ L locks.
