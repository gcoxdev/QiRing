Help

Getting started

QiRing is a local-only, offline-first password manager. Everything below is stored and computed on this device; nothing is uploaded or synced anywhere.

Qi
One saved credential entry — a login, secure note, and everything attached to it (username, password, URL, TOTP, notes, security questions, history, icon).
Ring
The encrypted collection holding every Qi, password profile, and setting. Unlocking decrypts it into memory for this session only.
Ring index
The searchable, categorized list of all your Qi, shown on the left side of the Ring page.
Master password
The password you set when creating the Ring. It never leaves this device and QiRing cannot recover it if it is lost — only the recovery key can.
Recovery key
A separate, one-time-shown credential that can unlock the Ring if the master password is forgotten. Store it offline, away from this computer.

Create, unlock & recovery

The first time QiRing runs, it shows only the Create Ring screen. After a Ring exists, it shows only the Unlock screen. The authenticated Ring workspace appears solely after a successful unlock.

Master password (create)
Sets the password that unlocks this Ring going forward. Must be at least 12 characters. Choose something you can remember but nobody else could guess.
Confirm master password
Must exactly match the master password above before the Ring can be created.
Master password tab (unlock)
The normal way to unlock: enter the master password you created the Ring with.
Recovery key tab (unlock)
Use only if you have forgotten the master password. Requires the recovery key plus a brand-new master password, and immediately retires the old recovery key.
Recovery key (recovery unlock)
The offline key you saved during the recovery ceremony. It is single-use: a successful recovery unlock issues a new recovery key and invalidates this one.
New master password (recovery unlock)
The replacement master password to set while recovering Ring access.
Confirm new master password
Must exactly match the new master password above.

QiRing cannot retrieve either secret if both are lost — there is no back door. Store the recovery key somewhere separate from this computer (printed, or on another device), and use Lock whenever you step away.

The recovery ceremony

Creating a Ring, migrating an older Ring, recovering with the recovery key, or replacing the recovery key in Settings all trigger a mandatory recovery ceremony before you can continue:

Copy
Copies the new recovery key to the clipboard so you can paste it into a password manager entry or secure note elsewhere.
Save private text file
Writes the recovery key to a plain-text file you choose the location for — ideally on removable media, not this device's normal backup folder.
Print key
Sends the recovery key to a printer so a paper copy can be stored offline.
Show QR code
Generates a scannable version of the recovery key locally in the recovery dialog. Reveal it only when needed and scan it only into a trusted offline destination; the QR is cleared when the ceremony ends.
Fingerprint
A short check value derived from the key. Compare it against another copy to confirm you recorded the key correctly.
Type the final six characters
Proves you actually recorded the key (not just clicked through) before QiRing will accept it as stored.
“I stored this recovery key somewhere safe”
A required acknowledgment. The Continue button stays disabled until the verification text and this box both check out.

Ring & Qi editor

The Ring page has two panes: the searchable Qi index on the left and the selected Qi's editor on the right. Header actions for New Qi, Save Qi, and Delete Qi appear before the menu whenever this page is open.

Ring index (left pane)

Sort control
Cycles between Custom (your own drag-and-drop order), A–Z, and Z–A. Custom mode remembers its order even while you temporarily use an alphabetic mode.
Expand all / Collapse all
Opens or closes every category group at once. Categories with search or tag matches expand automatically regardless of this setting.
Item count
The number of Qi currently visible in the Ring, after any search or tag filter is applied.
Search
Matches Qi names, usernames, notes, and tags as you type. Debounced briefly so fast typing does not spam requests.
Clear
Resets both the search text and the tag filter in one action.
Tag filter
Narrows the Ring to Qi carrying one exact tag, populated from every stored tag.
Drag grip
In Custom sort mode, drag a Qi or category grip to reorder it, or focus the grip and use the arrow keys — see Navigation & shortcuts.

Qi editor — Info

Name
The display name for this Qi, shown throughout the Ring and in delete/restore confirmations. Required.
Type
Login shows the credential fields below; Secure note hides them so the entry is just a protected note.
Category
Groups this Qi under a heading in the Ring. Pick an existing category from the list or type a new one.
Qi icon
A small image shown next to this Qi in the Ring, stored inside the encrypted Ring. Limited to 512 KiB.
Upload
Choose a local PNG, JPEG, WebP, GIF, or ICO image from disk to use as this Qi's icon.
From website
Fetches the site's favicon directly from its own server (no third-party lookup service). This reveals your IP address and the hostname to that site.
Remove
Clears the current icon back to the default placeholder.
Tags
Comma-separated labels used by Ring search and the Tag filter.

Qi editor — Credentials

Website
The login URL. Open launches it in your default browser; only http:// and https:// links are permitted.
Username
The account identifier. Copy places it on the clipboard.
Password
The account password, masked by default. The live meter estimates strength from length and character variety before you save; Ring Health remains the separate audit for weak, reused, and old credentials. Show/Hide toggles visibility (it automatically re-masks when you switch to another Qi); Copy places it on the clipboard.
Password profile
Selects which saved generation policy Generate password will use for this Qi.
Generate password
Fills the Password field with a new password matching the selected profile's rules.
TOTP secret (Base32)
The one-time-code setup key from the website's two-factor setup screen, usually shown as a Base32 string or QR code.
Show current code
Computes and displays the current 6-digit TOTP code from the saved secret and the device clock, refreshing on the standard 30-second window.

Qi editor — other sections

Notes
Free-text secure content, encrypted with the rest of the Qi. Up to 100,000 characters.
Security questions
Optional question/answer pairs for sites that require them. Add question appends a new blank pair; each answer has its own copy button.
Custom fields
Add labeled values such as PINs, membership numbers, account IDs, or security codes. Secret fields stay masked in the editor, and all values are encrypted with the rest of the Qi. Custom-field labels and values are also included in Ring search.
Password history
Shows previous passwords this Qi has used, kept automatically so you can recover an older value if a change was a mistake.

Save before leaving an edited Qi, or QiRing will offer to save, discard, or let you stay. Deleting a Qi asks for confirmation naming the entry and offers a temporary Undo from the resulting notification.

Password profiles

Profiles are reusable password-generation rules, listed on the left with the selected profile's editor on the right. New Rings include Strong 20, Strong 32, Website Compatible 16, and Alphanumeric 20 profiles. At least one profile must always remain.

Profile name
The label shown when choosing a profile elsewhere in QiRing.
Total length
How many characters a generated password will contain, from 8 to 256.
Minimum / Maximum (per character group)
The allowed count range for uppercase letters, lowercase letters, numbers, and symbols. Each range must satisfy 0 ≤ minimum ≤ maximum ≤ length, the minimums must not add up to more than the total length, and the maximums must be able to reach it. QiRing checks this live as you type and blocks Save/Test with an explanation if the ranges do not add up.
Allowed symbols
The exact set of symbol characters generation may draw from when the symbol maximum is above zero.
Avoid ambiguous characters
Removes easily confused characters such as I, l, 1, O, and 0 from generated passwords.
Test profile
Generates a sample password using the current, unsaved form values so you can preview a policy before committing to it.

Ring health

An entirely offline analysis of your saved credentials. No password, hash, or derived value is ever sent to a network service.

Run analysis
Inspects every Qi and reports password-specific findings for entries that contain a password. Re-run any time after making changes.
Analyzed
The total number of Qi inspected, including secure notes and entries without a password.
Weak
Passwords that are short or use too few character classes to resist guessing.
Reused
Passwords that appear identically on more than one Qi.
Old
Passwords that have not been changed in the last 180 days.
Open Qi (per issue)
Jumps straight to that Qi's editor so you can review and update it.

Encrypted backups

Backup passphrase (export)
A separate passphrase — distinct from your master password — that protects the exported backup file. Keep it somewhere other than alongside the backup itself. Show or hide it with the adjacent visibility button.
Choose destination and export
Opens a save dialog and writes a portable encrypted backup, protected by the passphrase above, to the chosen location.
Choose encrypted backup
Opens a file dialog to select a previously exported backup file to preview or restore.
Backup passphrase (restore)
The passphrase the selected backup file was exported with. Show or hide it with the adjacent visibility button.
Preview
Authenticates the selected backup with the passphrase and shows its Ring ID, creation date, schema version, and size before you commit to restoring it.
Restore previewed backup
Replaces the current Ring with the previewed backup and locks QiRing immediately afterward. Stays disabled until a preview succeeds. A recoverable safety snapshot of the current Ring is always taken first.
Automatic snapshots
Local safety copies of the Ring, still protected by the Ring's own encryption (not a separate passphrase), created automatically when enabled in Settings.
Refresh
Reloads the list of available automatic snapshots from the configured backup directory.
Restore (snapshot)
Replaces the current Ring with that snapshot and locks QiRing. QiRing refuses to restore a snapshot that does not belong to this Ring.

Settings

Settings are stored inside the encrypted Ring and enforced by the Rust service, not just the interface. Changes are not persistent until you choose Save Settings; QiRing prompts you to save or discard before navigating away or locking with pending changes.

Session

Auto-lock minutes
Locks the Ring after 1–1,440 minutes without qualifying activity, timed by the trusted Rust layer rather than the interface.
Clipboard clear seconds
Attempts to clear a copied QiRing secret after 5–300 seconds, but only if the clipboard still contains that exact value — copying something else afterward is left alone.
Lock when the window is minimized
Locks immediately whenever the QiRing window is minimized.
Lock when the window loses focus
Locks whenever you switch to another window. Enable for stronger shoulder-surfing protection on a shared or public machine.
Theme
System follows the operating-system appearance; Dark and Light keep a fixed QiRing theme regardless of the OS setting. The last saved choice is also remembered outside the encrypted Ring solely so the initial lock screen can use the correct appearance before you unlock.
Button display
Icon + label, Icon only, or Label only for supported controls. Navigation menu labels always stay visible; icon-only controls still expose their name on hover and to screen readers.

Automatic snapshots

Create a snapshot after Ring changes
Writes a new encrypted automatic snapshot to the backup directory after supported Ring changes.
Include encrypted settings in manual exports
Adds your application settings to newly created manual backup files, in addition to your Qi and profiles.
Snapshots to retain
Keeps the newest 1–100 automatic snapshots and deletes older ones beyond that count.
Backup directory
Where automatic snapshots and manual export/restore dialogs default to. Choose a durable, user-owned location — QiRing writes only the snapshot files here and does not otherwise alter this folder's permissions.

Master password

Current master password
Proves you are authorized to rotate the password before QiRing will proceed. Its adjacent visibility button reveals only this field.
New master password
The replacement master password. Existing Ring contents are kept; only the wrapping around the encryption key changes. The strength meter updates as you type, and the adjacent visibility button reveals only this field.
Confirm new master password
Must exactly match the new master password before rotation can begin. It has its own visibility button.
Rotate master password
Verifies the current password, re-encrypts the Ring key under the new password, and asks for confirmation first since the old password stops working immediately.

Recovery key

Master password (recovery key)
Confirms you are authorized before a new recovery key can be issued. Use its adjacent visibility button when you need to verify the entry.
Replace recovery key
Verifies the master password, immediately invalidates the old recovery key, and starts the mandatory save/verify ceremony for the replacement. Asks for confirmation first.
